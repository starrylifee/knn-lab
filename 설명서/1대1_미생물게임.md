# 1:1 미생물 배양 대작전

주소: https://knn-lab.vercel.app/microbe.html

1~15번 방을 고정으로 표시한다. 방 하나에는 두 명만 입장하며, 둘 다 **게임 준비**를 누르면 시작한다. 한 사람만 준비했을 때는 시작하지 않는다. 한 브라우저의 익명 계정은 한 방만 이용할 수 있다. 두 사람이 각각의 기기로 접속한다.

한 판은 12차례다. 1판 종료 후 둘 다 준비하면 색과 선공을 바꾸어 2판을 진행한다. 두 판 합계로 승패를 정하고 동점이면 무승부다. 이는 색·선공 기회를 맞추는 장치이며 모든 실력 수준의 승률이 정확히 50%라는 뜻은 아니다. 실물 v2 인쇄 규칙은 한 판 기준이다.

후보 세 곳·카드 순서·K는 서버에서 무작위로 정한다. 자리와 카드를 정한 뒤 K를 공개한다. 재실험은 한 번만 가능하며 두 번째 결과가 최종이다. 태어난 색에 점수를 준다. 일반 1점, 각 판 7~12차례 금색 자리 2점, 영양분 카드 추가 1점이다. 시작 세균은 0점이다.

새로고침 시 같은 계정과 방으로 복구된다. 진행 중 방 나가기는 기권이다. 두 사람 모두 10분 넘게 접속하지 않은 방은 다음 입장 시 정리된다. 상대가 잠시 연결을 잃었다고 자동 패배시키지는 않는다.

## 구현과 검증

- `api/microbe.js`: Firebase 익명 인증을 검증하고 Firestore 트랜잭션으로 두 자리와 차례를 관리한다. 브라우저가 점수·K를 지정할 수 없으며 미공개 덱은 응답에 넣지 않는다.
- `lib/microbe-engine.js`: v2 배치와 정확한 거리순 KNN 판정, 두 판 합산.
- 기존 Firestore 규칙은 새 게임 컬렉션에 대한 브라우저 직접 접근을 허용하지 않는다. 서버 전용 서비스 계정으로 처리한다.
- `npm test`: 규칙 테스트 7개. `npm run test:api`: 실제 인증·DB를 사용하는 두 판 24차례 통합 테스트. `python tests/microbe-browser.py`: 서로 분리된 PC/모바일 브라우저에서 입장·준비·한 차례·새로고침 검사. 테스트 계정과 사용한 방은 종료 시 정리한다.
- 앱 제작 전 v2 추가 10판은 계산 모의이며, 실제 학생 10판이나 30명 동시 부하 검증은 아니다. 기록은 `수업자료/05_보드게임/playtest`에 있다.
- 카드 SVG 독립 검토: 카드 88점, A4 89점. 앱 합성 장면: PC 91점, 모바일 87점.

## 배포

`tools/deploy-app.ps1`은 앱 파일만 임시 폴더에 복사해 기존 Vercel 프로젝트에 배포한다. 수업자료·연구 파일·로컬 환경 파일을 업로드하지 않는다. `FIREBASE_SERVICE_ACCOUNT_JSON`은 Vercel Production의 Sensitive 환경 변수다. 자격 증명을 소스나 문서에 넣지 않는다.

Node 22와 Firebase Admin 13.10.0을 사용한다. Admin 14의 인증 의존성이 배포 환경에서 ESM 로드 오류를 내어 호환 버전으로 고정했다. npm audit의 중간 등급 전이 의존성 경고는 남아 있으며, 메이저 강제 다운그레이드나 임의 override는 적용하지 않았다.

## 이용 시간과 요청 절감

한국 시간 평일 09:00 이상~14:30 미만에 열리며 주말에는 닫힌다. 시간 밖에는 입장 코드로 해당 탭을 열 수 있다. 입장 코드는 소스에 두지 않고 Vercel 환경 변수 `MICROBE_ACCESS_CODE`에 저장한다(로컬 실행 시에도 같은 이름의 환경 변수 필요). 오후 2시 30분에는 진행 화면도 잠기며 코드를 입력해 이어갈 수 있다. 서버도 모든 게임 요청에서 시간을 확인하므로 기기 시간을 바꾸어 우회할 수 없다. 방 나가기는 닫힌 시간에도 정리를 위해 허용한다.

닫힌 화면은 최초 시간 확인 뒤 자동 API 조회를 멈추고 다음 평일 개장 시 다시 확인한다. 열린 화면은 5초 간격으로 조회하고 숨겨진 탭과 이전 조회 진행 중에는 요청하지 않는다. 방 목록은 서버 인스턴스 안에서 최대 5초 재사용한다. 이 설정은 불필요한 요청을 줄이지만 서버 전체에 대한 공격 방어나 비용 상한을 보장하지는 않는다.
